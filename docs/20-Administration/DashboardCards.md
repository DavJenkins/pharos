# Landing-page collections

The landing page groups installed content by purpose. `dataark.yaml` contains a `dashboard` presentation section; the portable `config/content/public-manifest.yaml` includes it for recovery. Underlying collection IDs, installed files, update recipes and ownership remain unchanged.

Custom cards use stable repository anchors, repository and asset IDs, labeled local link groups, and existing artwork. Explicitly assigned assets appear on their chosen card rather than twice. Individual-file lists can be collapsed. Maps combine street maps and clearly scoped Massachusetts reference layers. Learning is separate from activities; wilderness skills from energy; repairs and vehicle manuals share a card with labeled subsections; radio combines emergency communications, exam practice, callsigns and Part 97.

All 301 active assets remain represented across 23 collection cards. WikiMed remains separate from first aid, with a cross-link. Manage Library continues to operate on original collections.

The header uses the exact user-supplied PHAROS / DATA ARK image, including its stone backdrop, with an accessible heading and responsive dimensions. Asset: `app/static/assets/pharos-data-ark-source.png`. The image is copied without regeneration or alteration to preserve the original lettering. No network font or image dependency is required.
