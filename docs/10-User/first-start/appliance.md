# First start: Complete appliance

[Choose a different distribution path](../FirstStart.md) · [Download printable guide](../assets/data-ark-first-start-appliance.pdf)

A complete Data Ark includes its host and prepared system storage, with either an external library drive or a system-drive library. Installed content needs no internet connection.

## What you need

- The supplied host, system storage, power supply and any supplied library drive.
- A browser device on the hotspot or the same local network.

## First start

1. Connect the supplied library drive, if any, before applying power.
2. For a hotspot appliance, join its supplied Wi-Fi network and open http://192.168.4.1/setup.html.
3. For a LAN appliance, connect it and your browser to the same local network; use the device address supplied with it.
4. If first-owner setup is pending, enter the supplied private code and choose the two passwords. If the owner already set credentials locally, no additional code step is needed.

## Setup authorization

Use the private four-digit code supplied for this particular card or appliance when browser first-owner setup is pending. The supplied-card sheet and public guide use the same template; the public copy never includes a real code. Local setup can establish credentials without a code.

No online activation, DEJ Software account or registration is required. A new recipient gets a fresh identity and code rather than inheriting the original owner’s credentials.

## Hardware and operating notes

- Keep the supplied storage attached while the appliance is running.
- Use System / System / Power to restart or shut down safely. A shutdown requires someone to power the device back on.
