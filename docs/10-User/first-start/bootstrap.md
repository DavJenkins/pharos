# First start: Software / bootstrap kit

[Choose a different distribution path](../FirstStart.md) · [Download printable guide](../assets/data-ark-first-start-bootstrap.pdf)

The downloadable kit supplies software and public collection configuration. You supply the host and storage. It is not a complete operating-system image and does not include the public collection.

## What you need

- A supported Linux installation, administrative access, storage and internet for installation.
- The verified bootstrap kit and its matching README.

## First start

1. Download the kit and checksum from the DEJ Software bootstrap page or the Ark's DEJ Software collection.
2. Extract the kit onto a formatted content drive or the installation location described by its README.
3. Review the preview, select the platform profile and library location, then complete installation with local administrative authorization.
4. Set credentials in the trusted installer. If you deliberately defer first-owner setup to a browser, prepare a unique code and supply it privately before exposing that setup page.

## Setup authorization

Set credentials through the trusted local installer or Docker host terminal. No separate activation code is required afterward. If browser setup is deliberately deferred over a shared network, recipient preparation supplies a new private pairing code.

No online activation, DEJ Software account or registration is required. A new recipient gets a fresh identity and code rather than inheriting the original owner’s credentials.

## Hardware and operating notes

- Original Raspberry Pi provides the optional hotspot appliance profile. LAN-only Debian hosts serve an existing wired or Wi-Fi network.
- Content acquisition is separate from installing the software; choose only the collections that fit.
