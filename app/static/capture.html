Capture a public download

Choose a missing public reference or review an update. Chrome or Chromium downloads it normally; the helper validates it and imports it into the Ark. Installed copies remain available. Completed personal forms must never be imported.

Broken links need a source repair; browser checks need a normal browser download. Related replacement publications are offered for review, never imported as an identical edition. Installed copies with recently verified browser captures remain below under no action needed.

Extension setup and troubleshooting

On the Pi: use Chromium. After the one-time local installation, fully quit and reopen it, then return here. Pi setup instructions.

On Windows: download the Chrome capture package, extract it, run install.cmd (in PowerShell: .\install.cmd), then load that folder in Chrome Extensions using Developer mode and Load unpacked.

If PowerShell says “running scripts is disabled”, use install.cmd. It applies an execution-policy override only to the installer process, without changing your saved policy. Troubleshooting and equivalent PowerShell command.

If automatic downloading is refused, use Open publisher, then click the PDF viewer’s download button. Capture remains armed for ten minutes. Chrome may still ask where to save if “Ask where to save each file” is enabled.

Checks are manual. A blocked check does not mean a new edition exists. A browser comparison that matches the installed file resolves the request.

Replacement captures preserve the previous verified file. Year-specific forms keep their pinned year; a new tax year requires a separate catalogue entry.
