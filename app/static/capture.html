Capture a public download

Choose a missing public reference or review an update. Chrome downloads it normally; the paired desktop helper validates it and imports it into the Ark. Installed copies remain available. Completed personal forms must never be imported.

Download Chrome capture package. One-time setup: extract it, run install.ps1, then load its folder in Chrome Extensions with Developer mode → Load unpacked. Full instructions.

Checking for the extension…

If automatic downloading is refused, use Open publisher, then click the PDF viewer’s download button. Capture remains armed for ten minutes. Chrome may still ask where to save if “Ask where to save each file” is enabled.

Checks are manual. A blocked check does not mean a new edition exists. A browser comparison that matches the installed file resolves the request.

Replacement captures preserve the previous verified file. Year-specific forms keep their pinned year; a new tax year requires a separate catalogue entry.
