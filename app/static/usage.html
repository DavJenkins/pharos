    What is measured?

    Hotspot devices are Wi-Fi stations connected directly to the Ark. Remote access counts established SSH, VNC desktop and browser-terminal TCP connections; a user or session may have multiple connections.

    The all-time estimate deduplicates client addresses across days using a persistent HyperLogLog sketch, with about 0.8% relative standard error from the sketch itself. Address changes and sharing add separate uncertainty. It starts when enabled and survives restarts; it is not reconstructed from daily totals. Its start date is shown on the all-time tile.

    Estimated visitors count distinct client addresses making qualifying document requests per UTC day. Shared addresses can undercount; address changes can overcount. These are not identified people, and daily counts cannot be added to get weekly unique visitors. Private daily salted hashes expire after two days; only counts are public. Visitor counting starts separately from older request totals.

    Web statistics cover successful GET requests in the Ark’s Apache access log: document pages, collection files and downloads. API/status polling, static interface assets, JSON and loopback traffic are excluded. Direct Kiwix reader traffic on port 8080, FTP, SMB and other direct services are not included in web totals.

    Collection names, hourly totals for 30 days, and daily totals for one year are retained locally. This monitor stores no visitor addresses, individual URLs, query strings or user agents. Existing server logs have their separate retention. Totals start when monitoring is enabled; blank days mean no observations, not zero use. Hotspot peaks are sampled and can miss short connections. Bytes are response payload bytes, not total network traffic.
