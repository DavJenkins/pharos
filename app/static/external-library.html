Use an external library drive

Transfer existing content from the system card without downloading it again.

1. Choose a drive

Connect an empty, formatted USB drive. Nothing is formatted or erased. The complete library must fit, with at least 1 GiB left free. The original system-card copy is retained.

For a populated Ark drive or an empty replacement when the original is missing, use Library storage.

2. Copy existing content and verify

Existing editions are copied as they are, including usable older editions. After switching, publisher checks can identify updates; only missing content or selected updates need downloading. No internet connection is needed for this transfer.

The Ark’s API and reader may be temporarily unavailable while the library is kept still for copying. Keep both drives connected and power on.
