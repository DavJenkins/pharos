Prepare a ready-to-run system card

Write installer media, let the Pi build the Ark, then hand over a card that starts offline.

1. Build the preparation package

Capacity is reserved space, not a promise of a full library. The package carries software/configuration and fixed demo samples; large optional restores are separate. The OS image is not included.

2. Write a chosen card

Extract the ZIP on Windows or a Linux/Pi computer with a card reader. Obtain the exact reviewed Raspberry Pi OS image listed inside and install official Raspberry Pi Imager. Run prepare-card.cmd in an Administrator terminal on Windows, or sudo python3 prepare-card.py on Linux.

The writer lists eligible disks and requires an exact ERASE disk + serial confirmation. It refuses system disks, active library disks and a disk containing the input image/package. It verifies the OS image, write and copied kit. Keep the private welcome sheet it creates.

3. Build, then hand over

Boot the new card in a compatible Pi with Ethernet and internet. Installation runs automatically and records progress. A successful build prepares fresh recipient setup and powers off. Only then is the card ready to give away. A failed build retains logs and its resumption journal.

The recipient’s next boot works offline, serves installed content and asks for the supplied four-digit code and new caretaker/Linux passwords. No shared root password or provisioner SSH key is carried over.

The private HTML welcome sheet can be printed or saved as PDF. A prepared complete appliance follows the same recipient preparation flow.
