Use a file manager

Windows File Explorer: \\dataark\Offline-Archives

macOS Finder → Go → Connect to Server: smb://dataark/Offline-Archives

The library share is read-only. Use your Samba account if your computer requires sign-in. The separate Bugout-Staging share remains the upload area.

Use the SSD without the Pi

Shut the Pi down cleanly, wait for shutdown, then disconnect the SSD. Attach it to another computer and open the OfflineRepo volume. Start with START-HERE.html or README-DATA-ARK.txt.

The SSD uses exFAT. Keep the original files; do not reformat it. Open ZIM archives using a compatible Kiwix reader. The catalog identifies any Windows reader programs present; keep compatible readers for the devices you intend to use.
