Access your content

Read the public library on the Ark, copy it to another device, or use the SSD directly. The content available depends on what is installed. Reading and copying require no caretaker password.

Download original files over HTTP

Content catalog and reader instructions · Browse SSD files

Use the browser's download command or a download client. Large archives need sufficient destination space. A client that supports HTTP resume can resume transfers when the file and server permit it. Online source links require internet; local file links use this Ark.

Copy with a file manager — SMB

Windows File Explorer: \\dataark\Offline-Archives

macOS Finder → Go → Connect to Server: smb://dataark/Offline-Archives

The library share is read-only. Guest access depends on your device's policy; use an authorized Samba account if required. The separate Bugout-Staging share is an upload area, not the anonymous library. Samba credentials are separate from the caretaker password.

Anonymous read-only FTP

Use an FTP client with host dataark, port 21, username anonymous, no password, and passive mode. Open the /library folder.

FTP supports public file downloads and resumable transfers. Upload, rename and deletion are disabled; private and staging directories are excluded. No account is needed. Most current web browsers do not include an FTP client; use a dedicated client or HTTP downloads instead.

Administrator transfers — SFTP and rsync over SSH

SFTP is available through the existing SSH service at dataark, port 22. Sign in with an authorized Pi account and use /mnt/storage. Its account permissions apply; this is not anonymous access.

Administrators can also pull files using rsync over SSH for resumable or scripted copying. There is no anonymous rsync daemon. SSH authentication is separate from the library's shared caretaker password. Ordinary readers should use HTTP, SMB, or anonymous FTP.

Use the SSD without the Pi

Have a caretaker shut the Pi down cleanly, wait for shutdown, then disconnect the SSD. Attach it to another computer and open the OfflineRepo volume. Start with START-HERE.html or README-DATA-ARK.txt.

The SSD uses exFAT. Do not reformat it. ZIMs, PDFs, GIS files and program packages still need suitable software on the receiving computer. Keep reader dependencies together.

The Ark's own source code

The working Git checkout is /opt/dataark on the Pi. The existing local development share is \\dataark\dataark (SMB, subject to its account permissions). It is separate from the anonymous public-library FTP view.

Add or remove a collection

Use Settings → System → Manage Library on the landing page. Caretaker authentication protects changes to the shared collection; copying public content does not require it. Removal retains supported source information for later reinstatement.
