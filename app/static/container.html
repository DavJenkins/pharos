Refresh the displayed collection

Edit the mounted public configuration on the host, or copy configured content onto the library drive. Reload validates the configuration and rebuilds the dashboard. It starts no downloads.

Administration

The container runs without privileged mode, host networking, physical devices or the Docker socket. Wi-Fi, storage mounting, software updates, optional HTTPS and file-sharing services are managed on the host.

Content is mounted read-only. The community board and banner remain writable in persistent state. Configuration inspection and validation are available; edit the mounted YAML on the host and reload to publish changes.

Set the caretaker password privately from a host terminal:

docker compose run --rm ark caretaker-password

Use the same Compose file and environment options as when starting this Ark. Browsing requires no password. There is no shared root or caretaker password.
