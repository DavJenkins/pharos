Wi-Fi adapter assignment

Choose which radio serves the DataArk hotspot. The other radio handles optional upstream Wi-Fi. Saved network names and passwords are retained.

Changing roles disconnects Wi-Fi clients briefly. Reconnect to DataArk, return here, and confirm within four minutes. Otherwise the previous assignment is restored automatically. Ethernet stays available. Internet pass-through resets to off.

If the chosen USB adapter is missing at startup, the built-in radio provides the hotspot. The preferred adapter is remembered for the next startup.
