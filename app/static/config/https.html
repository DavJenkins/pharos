Configure when you’re ready

You need internet access and permission to add a DNS record for your domain. No incoming port forwarding is needed. HTTPS certificates expire; this manual DNS workflow needs your help again for renewal.

1. Your domain

The domain and contact email are sent to Let’s Encrypt to request the certificate. DNS records and certificate domain names are public.

2. Add the temporary DNS record

At your domain provider, add the following TXT record. Use its DNS editor’s full-name or relative-name convention. Wait for the change to become publicly visible, then choose Verify DNS.

3. Connect with HTTPS

After verification, the Ark validates the certificate and enables HTTPS. The DataArk hotspot will resolve your domain to 192.168.4.1. On another network, configure that network’s DNS or a device hosts entry to point the same name to the Ark’s address.

HTTP stays available. Existing book readers, file shares and other access methods remain available. This certificate configures the main web interface; separate remote-access tools keep their own settings.
