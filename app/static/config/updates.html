Checking software availability does not change the Ark or download a kit.

What gets updated?

  • Ark software: the dashboard, API, tools and bundled handbook. An update must preserve configuration, content, community data, credentials and this device’s identity.
  • Library content: books, maps, courses and other collections use their own publisher schedules in Manage Library.
  • Operating system: Debian packages, security fixes, drivers and firmware need a separate maintenance operation and may require a restart.

Software releases download directly to the Ark. Bootstrap/recovery kits are for building an Ark and are not in-place software updates. Read the software update workflow.
