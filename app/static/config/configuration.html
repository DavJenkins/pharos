Configuration files

Start with ark.yaml for main settings. Collection definitions and detailed publication catalogues are separate files; generated checksum/order snapshots are read-only. Private household settings are preserved separately. Storage/service paths are read-only here.

Saving assembles the files into the compatible dataark.yaml, publishes the page and mirrors the public manifest. It starts no collection downloads and removes no content. Collection source catalogues and restoration recipes are separate configuration files; the editor does not replace acquisition handlers or the separate restoration recipe.
