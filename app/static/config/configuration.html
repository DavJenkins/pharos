Configuration files

Edit the Ark’s public settings and collection definitions. Saving requires the caretaker password.

How configuration files work
  • ark.yaml: main settings.
  • collections/: collection descriptions and presentation.
  • catalogues/: publications and download definitions.
  • state/: generated, read-only snapshots.

Private settings remain separate. Storage and service paths are read-only here.

Publishing updates configuration and pages; it does not download or remove content. Files are assembled into the compatible dataark.yaml and mirrored for recovery. Acquisition handlers and the restoration recipe remain separate.
