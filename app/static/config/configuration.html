Content configuration file

The public settings from dataark.yaml: sections, collections, artwork, links, display choices and content metadata. Private household settings are preserved separately. Storage/service paths are read-only here.

Saving publishes the page and mirrors the public manifest. It starts no collection downloads and removes no content. Collection source catalogues and restoration recipes are separate configuration files; this first editor does not replace those files or their handlers.
